# This file describes how to compute the MDCI and DCI

About

R version 4.0.2 was used with R studio version 1.3.1056

The R packages dplyr, tidyr, parallel and haven were used for data management, parallel computation (needed for large data sets) and for reading SAS-files.

An input dataset with a unique identifier per individual (LopNr) and one or more dates (indexdate) is needed for both the MDCI and DCI. The Swedish Patient Register and The Prescribed Drug Register are needed and all codes / drugs / visists during the preceeding 10 / 1 year Before the index date are needed for correct computation. See the weight files for the lists of codes needed.


### ### ### ### ### ### ### ### ### ### ### ##




### FOR EXAMPLES OF HOW DATA NEEDS TO BE STRUCTURED - see folder "Processing patient and drug register" ### 




### ### ### ### ### ### ### ### ### ### ### ##
MDCI: to compute the MDCI the scripts mdci_inner.R, process_data.R and compute_mdci_function.R are needed (see below) along with the weights in mdci_weights.Rdata. The code is written for The Swedish Patient Register (inpatient+specialized outpatient register) and may need modification if Another dataset is used. The Patient Register was split into separate parts based on LopNr (modulo X) and saved as Rdata-files called par_partx where x indicates the number of the part (1-X). The following variables are required to be present in each par_part file

LopNr, indatum, utdatum, hdia, diagnos, source (inpatient="sluten" and outpatient="oppen"; manually added after combining the two subregisters)

No other preprocessing was performed. 


### ### ### ### ### ### ### ### ### ### ### ##
DCI: to compute the DCI the script compute_dci_function.R (see below) is needed along with weights Men.RData and Women.RData. The code is written for The Swedish Prescribed Drug Register and may need modification if Another dataset is used. To facilitate parallel computation, The Prescribed Drug Register was split into separate parts based on LopNr (modulo X) and saved as Rdata-files called drug_partx where x indicates the number of the part (1-X). The following variables are required to be present in each drug_part file

LopNr, ATC, EDATUM

No other preprocessing was performed.
